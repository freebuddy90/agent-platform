# agent-platform

任务型智能体平台研发仓库。

## 目录组织

| 目录 | 职责 |
| --- | --- |
| `00_总体研究/` | 总体说明、概念体系、研发方法与工作规程 |
| `10_研究与工程设计/` | 持续演进的领域模型、核心机制、需求与工程设计 |
| `20_研发迭代/` | 迭代台账、研发与验证方案、研发结果与分析 |
| `30_实验与验证/` | 可复用实验原型、样本、验证脚本和运行记录 |
| `src/` | 正式工程代码 |
| `tests/` | 自动化测试与回归验证 |

正式研究与设计成果随研发迭代按需更新。每轮实验的实际证据独立记录，并引用对应方案及代码版本。未开始的研究和设计不预先填充。
